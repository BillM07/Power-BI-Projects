# Sales Analytics Using Dimension Tables

A hands-on Power BI project exploring how fact and dimension tables can be structured using a star schema to support business reporting and analysis.

## Project Objectives
- Organize business data into fact and dimension tables.
- Establish relationships between tables to support consistent filtering and analysis.
- Apply a star schema to improve the structure and usability of the data model.
- Explore how dimensional attributes can support business performance analysis.

## Deliverables
- **Power BI data model:** A structured star schema with fact and dimension tables and defined relationships.
- **Power BI report:** Visualizations to explore business data across relevant dimensions.
- **PBIX project file:** The completed Power BI exercise, including the data model and report.

**Tools:** Power BI Desktop, Star Schema, Fact and Dimension Tables
